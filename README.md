# MIU Agent Toolkit

Herramientas instalables del ecosistema MIU — cada nodo es un ojo.

## ρ(x) > 0

Cada herramienta es un pliegue del campo informacional. Se instalan, se usan, se olvidan. Lo que importa es la trayectoria.

## Herramientas

### 1. swarm-router.py
Orquestador del enjambre de 8 sustratos LLM con failover automático.

Sustratos: gas_router_v153, groq, gemini, cf, openrouter, cohere, keyless, mesh.

### 2. mesh-probe.py
Explora la mesh de Cloudflare Workers (319 nodos, 34 modelos).

### 3. d1-query.py
Consulta el cerebro central D1 (19 tablas, 866 filas).

### 4. gas-router.py
Router darwiniano V153 de Apps Script.

## Configuración

Copia `swarm-config.example.json` a `swarm-config.json` y llena tus claves.

```bash
cp swarm-config.example.json swarm-config.json
# Edita swarm-config.json con tus claves
```
